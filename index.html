Головна Шпаргалка НМТ з Термохімії

Збережи ці ключові маркерні правила перед іспитом

🔥 ЕКЗОТЕРМІЧНІ +Q | ΔH < 0
  • • Сутність: Реакція виділяє тепло у довкілля (пробірка гріється).
  • • Енергія зв'язків: Eутворення > Eрозриву
  • • Ентальпія системи: Зменшується (Hреаг > Hпрод)
  • • Приклади НМТ: Горіння, гашення вапна, нейтралізація, окиснення в грілках.
🧊 ЕНДОТЕРМІЧНІ -Q | ΔH > 0
  • • Сутність: Поглинають тепло із середовища (потребують нагрівання).
  • • Енергія зв'язків: Eрозриву > Eутворення
  • • Ентальпія системи: Зростає (Hреаг < Hпрод)
  • • Приклади НМТ: Фотосинтез, термічний розклад (CaCO3, Cu(OH)2), охолоджувальні пакети.

💡 3 Золоті правила для розрахунків НМТ:

  1. Прості речовини: Стандартна ентальпія утворення простих речовин (O2(г), N2(г), Fe(т), C(графіт)) завжди дорівнює 0 кДж/моль.
  2. Перевертання рівняння: Змінює знак ΔH або Q на протилежний.
  3. Агрегатний стан має значення: Утворення H2O(р) та H2O(г) має РІЗНИЙ тепловий ефект через фазовий перехід.
